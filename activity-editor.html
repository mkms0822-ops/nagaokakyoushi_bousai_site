記録の一覧

新しい順に並びます。「編集」で内容や写真・動画を直せます。ここで変えた内容は、「公開用ファイルを書き出す」まではサイトに反映されません。

サイトに反映する手順

  1. 上の「⬇️ 公開用ファイルを書き出す」を押すと、ZIPファイルがダウンロードされます。
  2. ZIPを開くと、activity-log.js と activity フォルダ（新しい写真・動画）が入っています。
  3. GitHubのリポジトリの一番上（index.html と同じ場所）に activity-log.js を上書きでアップロードします。
  4. activity フォルダの中のファイルを、リポジトリの activity フォルダにアップロードします（初回はフォルダごと）。GitHubの画面からアップロードできるのは1ファイル25MBまでです。
  5. 記録や写真・動画を削除した場合は、ZIPの中の「アップロード手順.txt」に、消してよいファイルの名前が書いてあります。

次に記録を追加するときは、このページをサイト上で開けば今の記録が自動で読み込まれます。パソコンに保存したファイルから続けるときは「📂 activity-log.js を開く」を使ってください。
